## Design Guidelines for All Slides

### Color Palette
- **Background:** #1a1a2e (dark blue-black)
- **Primary Text:** #ffffff (white) with text-shadow: 0 0 2px rgba(255,255,255,0.8)
- **Secondary Text:** #c0c0c0 (silver) with text-shadow: 0 0 3px rgba(192,192,192,0.6)
- **Accent 1 (success):** #00ff88 (bright green)
- **Accent 2 (danger):** #ff4444 (red)
- **Accent 3 (highlight):** #88ccff (cyan)
- **Code/Data:** #ffcc88 (amber)

### Typography
- **Headings:** Montserrat Bold, 48-72pt, white with glow
- **Body:** Open Sans Regular, 24-32pt, silver
- **Code:** Fira Code, 20-24pt, amber
- **Emphasis:** Bold + 2px white glow

### Visual Elements
- **Borders:** 2px solid silver with 50% opacity
- **Dividers:** 1px silver horizontal rules
- **Backgrounds:** Gradient from #1a1a2e to #0f0f1e
- **Icons:** Line art style, white with glow

### Animation (if PowerPoint/Keynote)
- Slide transitions: Fade (0.5s)
- Text appears: Wipe from left (0.3s delay between bullets)
- Code blocks: Typewriter effect (if possible)
- Graphs: Animate growth lines
